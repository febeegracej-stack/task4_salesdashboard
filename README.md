# Task 4: Dashboard Design

## Objective
The objective of this task is to design an interactive dashboard for business stakeholders using Power BI. The dashboard provides insights into sales performance, customer behaviour, regional trends, and product category performance through interactive visualisations.

## Tools Used
- Power BI Desktop
- Microsoft PowerPoint
- GitHub

## Dataset
Sales Financial Dataset (Kaggle)

### Dataset Features
- Sale Date
- Sales Amount
- Quantity Sold
- Product Category
- Region
- Customer Type
- Sales Channel
- Payment Method
- Sales Representative
- Unit Price
- Unit Cost
- Discount

## Dashboard Components

### Key Performance Indicators 
- Total Sales
- Total Quantity Sold
- Total Product Count

### Visualisations
1. Monthly Sales Trend
2. Sales by Region and Customer Type
3. Sales by Sales Representative
4. Product Category Analysis
5. Unit Price and Unit Cost Comparison

### Interactive Filters
- Product Category
- Region
- Customer Type
- Payment Method

## Key Insights
- The dashboard provides an overview of overall sales performance.
- Sales vary across regions and customer segments.
- Product categories contribute differently to total revenue.
- Sales representatives show varying performance levels.
- Interactive filters allow stakeholders to analyse specific business scenarios.

## Business Value
This dashboard helps business stakeholders:
- Monitor sales performance.
- Identify high-performing regions and products.
- Analyse customer purchasing patterns.
- Support data-driven decision making.
- Improve strategic planning and forecasting.


This project demonstrates the use of Power BI to create interactive dashboards that transform raw sales data into meaningful business insights for decision-making.
